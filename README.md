### ▶ [virues134-source.github.io/Portfolio](https://virues134-source.github.io/Portfolio/)

## Contenido

- **Perfil:** titulado en DAM y SMR, técnico en sistemas, desarrollo y automatización con IA.
- **Proyectos:**
  - [LogSentinel](https://github.com/virues134-source/LogSentinel): detección de ataques en logs de SSH y servidores web, con [demo en directo](https://virues134-source.github.io/LogSentinel/).
  - [PokéLab](https://github.com/virues134-source/TFG): aplicación web con React, TypeScript, Spring Boot y PostgreSQL (proyecto final de DAM).
  - valvia.es: diseño de la web corporativa y desarrollo de su asistente con IA.
- **Trayectoria, habilidades y contacto**, con el CV en PDF descargable.

## Cómo está hecha

- HTML, CSS y JavaScript sin frameworks ni dependencias.
- Español e inglés, con el cambio de idioma guardado en el navegador.
- Diseño adaptado a móvil, navegación con teclado y respeto a la opción de reducir animaciones del sistema.
- Publicada con GitHub Pages.

Para verla en local basta con abrir `index.html` o servir la carpeta con cualquier servidor estático.
